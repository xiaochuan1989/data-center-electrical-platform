# v2.12.3 铜排指南模型

2026-10-11，按用户要求以2014铜排设计指南优化规格反算。计算依据、参数单位、可重复工况与适用范围见[指南模型](busbar-guide-model.md)。

## 变更

- 默认采用指南竖直/水平面分项自然对流，显示各面面积、L、h和散热量；沿长度竖直可填写实际散热高度。
- 辐射新增周围表面发射率和温度，按相对发射率计算；热壁面的负辐射计入热输入，净散热不正时阻止计算。
- 指南表面预设0.10/0.30/0.70/0.90与旧镀锡假设明确区分；模型和表面选择在主表单可见，结果显示ε及辐射环境。
- 新增100×10指南工况，旧模型和文章1762A独立复现保留；不使用不同边界差值判定准确性。
- 仅温度归一时保留辐射环境相对空气的温差；无法归一时明确提示。
