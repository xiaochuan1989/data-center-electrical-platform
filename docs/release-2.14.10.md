# v2.14.10 Excel 导出排版

2026-10-22。

## 背景

导出的"规范书设备参数工作稿"等 Excel 没有框线（还关闭了网格线），列宽、行高混乱：第一行的长说明（"未完成工作稿……"）被当作表头，既按表头样式显示，又参与列宽计算，把 A 列撑到上限、第 1 行撑高；真正的列标题在第 2 行却没有表头样式；行高按 18pt/行粗估，常有多余空白。

## 修复（`src/modules/presales-xlsx.js`，三处导出共用）

- 正文、表头、数值单元格加细框线；恢复网格线；表头深底白字。
- 工作表可指定列标题所在行（`header`）。其上的说明行用浅黄底加粗样式；单格说明合并到整表宽度，不参与列宽计算。AI 设备参数（第 2 行为列标题）、语义复核与未通过校验项（第 3 行）、设备合并记录（第 2 行）、技术要求工作稿（第 2 行）已标明；配置清单各表仍为第 1 行。
- 列宽按列标题与正文最长行计算（中文按 2.2 个字符单位），长文本列封顶 50 并自动换行；行高按换行后的行数估算（等线 11pt 约 15pt/行，上限 409），宁可略高不截字。
- 冻结到列标题下方；列标题行加自动筛选（含工作簿筛选区定义）；字体改为等线；打印 A4 横向。

## 验证

`npm test`（`test_nonstandard_deliverable.mjs` 新增：框线与样式、说明行合并、冻结与筛选、筛选区对含引号表名的转义、列宽不受说明行影响、表头行越界拒绝）、`python dev_scripts/test.py --quick`、`npm run test:build` 通过；内联脚本语法检查通过。以本机一份 AI 结果生成工作簿：各 XML 部件可解析，openpyxl 读出冻结、筛选、合并与框线正确；用 Excel 打开并截图核对"设备参数""语义复核"两表的框线、表头、说明行与列宽。
