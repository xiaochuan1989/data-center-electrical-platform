# 条款分页与按资料复核：定稿及验收方案

> 2026-10-01，先定稿再实施。接续[读取验收](local-file-reading.md)和[总计划](nonstandard-presales-roadmap.md)。只优化本机复核视图，不改提取/确认规则、v1数据契约、方案清单关系，不上传、不发布。

## 原因与本轮范围

真实5份资料形成1196个待分配/复核片段；当前视图为所有命中条款创建完整输入控件，每次commit重建全列表，待澄清及修订记录也全量生成。现有max-height只限制高度，不限制DOM数量。切筛选/其他commit还可能抹掉尚未点击分配/确认的行输入。

本轮用确定性分页代替全量控件，不新增虚拟滚动/前端框架、后端或新依赖。分页只是视图切片，不截断pack，不裁剪来源/候选，不改变全部JSON/Excel及采用方案的要求关联。提取算法、OCR、复杂表头归属与完整工程业务验收不在本轮。

## 已定交互

- 主列表默认20条/页，可选10/20/50，无“显示全部”。提供上一页、下一页、页码跳转；明确当前筛选总数、页数、显示区间、包内总数，空结果按0条/0页显示且按钮禁用。无效/越界跳转明确拒绝；数据减少时当前页自动钳制到有效末页。
- 新增独立“复核资料”筛选（默认全部）、关键词，与设备/状态取交集；“待处理”聚合未归属或非confirmed。关键词为普通文字匹配原文/字段/设备/位置及显式表头标题，不执行正则或文档指令；输入防抖250ms，Enter/其他筛选立即应用。
- “已导入来源”仍负责查看/提取/替换，不因查看原文而暗改复核筛选。新增“按选中资料复核”按钮；添加、文件导入、提取或替换来源成功后转到该资料第一页。JSON恢复回到全部资料第一页，筛选无效ID回到全部。
- 按来源登记顺序及原文位置稳定展示，不重排包内业务数组；重映射新ID/合并字段池后依据成功目标定位，若目标不符合当前筛选，说明它已移出，页码自动钳制。单条包含多份来源候选时，只要一候选符合资料筛选就入列，但显示并确认完整候选池，不能把其他资料的冲突隐藏掉。
- 待澄清显示全包待处理计数及最多20条摘要，标明仅摘要；“查看待处理条款”跳到主体待处理分页（当前资料/设备条件保留）。修订记录只显示最近20条及总数，明确完整记录在JSON/Excel，不偷偷删除旧记录。方案助手及导出仍读取完整包。

## 未保存输入与确认安全

- 按requirementId保存本次页面会话中的行编辑草稿：设备、字段、确认值、禁止偏离、人工应答、原因。切页/筛选/页大小或保存另一条/方案后回来仍还原输入，明确标“未记录编辑”；不自动分配/确认，不把草稿值写进pack。
- 已确认条款一经编辑立即撤销旧确认，既有方案确认失效规则不变；仅切页/筛选不改业务修订或取消确认。编辑的行暂时留在当前页，直到显式导航/提交再按新状态重筛选，不在打字中消失。
- 仅本机自动保存、JSON备份和Excel仍只含已记录pack，不含行草稿；有草稿时输出提示条数，明确未记录值不在文件中。页面刷新/关闭会丢会话草稿，存在草稿时启用浏览器离开提示（是否弹窗由浏览器决定），不许承诺跨刷新恢复。仍可主动放弃本次行草稿。
- 成功分配/确认/清空只清除该条草稿；错误保留输入。重映射合并/来源替换/重新提取造成ID或证据基线变化时清除相关草稿并告警，不套到新条款。无关条款/设备/方案修改不得清掉其他草稿。
- 恢复整个JSON前除原有确认与方案未保存保护，新增条款草稿放弃确认；取消保留当前包、筛选/页码与输入。成功恢复后清空旧草稿/视图位置，不自动恢复confirmed。

## 实施顺序与门禁

1. 新增可独立测试的分页/筛选/草稿管理纯模块；视图接入有界卡片、摘要、修订显示及草稿保留；保留事件委托和既有业务函数。
2. 纯回归验证1196/1500边界、分页不重漏、交集/关键词/跨来源池、越界/空、草稿提交与失效；全套npm、Python和构建门禁。
3. 隔离Chrome先小样本验证未保存输入跨页/筛选/其他commit保留、确认立即失效、错误输入保留、恢复取消/成功、输出不把草稿当采用值、XSS、1366/1920/900宽度；补跑原N2/N3与三品类关键兼容流程。
4. 复用被忽略的真实`output/playwright/local-file-reading/*/real-working.json`（5来源1196条），恢复并按资料/状态切页、首末/跳页、不同页大小、编辑/确认及完整导出；仍无需隐藏全部待复核控件来通过验收。开发与生产子路径复验，阻断外网，记录新时间戳、pageerror和响应耗时。
5. 本机目标：每页卡片≤页大小且最多50；待澄清/修订各≤20。首屏与切页/筛选/单条提交测试动作各≤5秒（排除文件解析、下载、人工确认等待；本机测试门槛不是跨设备SLA），记录中位数/最大值。真实条款/来源数不因分页减少，导出/备份全量且证据有效；不把视图显示数量当全部条款数量。

## 实际结果

隔离Chrome使用已有5来源1196条真实工作稿，阻断外部网络；全部状态正常显示，不再隐藏待复核列表。开发版与生产子目录版各遍历24页（50条/页），均收集1196个唯一ID，无重漏；20条模式末页16条，首末/跳页、五资料筛选、关键词及待处理通过。卡片最多50、两类摘要最多20，1366/1920/900宽度无横向溢出。
