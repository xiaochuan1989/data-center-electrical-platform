# v2.14.9 AI采用去除重复条款、撤销AI采用

2026-10-21。

## 背景

线上把一份 UPS 电池开关箱规范书的 AI 结果采用到人工复核后，49 条待复核条款中有多条原文完全相同（如两条"（1）户内"）。原因有两层：参数整理分段之间有重叠（3000 字分段、重叠 300 字），同一句会在相邻两段各提取一次；模型也常把同一句拆成名称不同的参数（如"安装场所""使用环境"）。提取阶段只在名称、值、证据位置都相同时去重；采用时证据又收窄到值所在段，这些参数就成了原文相同的多条条款。

## 修复

1. **采用时同句合并**（`src/modules/spec-adoption.js`）。证据收窄后落在同一段同一范围的参数合并为一条条款：名称合并显示（"防护等级 / 外壳防护"）；同句多个值时，值取覆盖各值的原文范围（仍原样出现在证据中）；任一参数为不可偏离则条款为不可偏离。提取结果本身不改动，AI 清单、导出与打分不受影响。
2. **撤销AI采用**（`withdrawAdoptedEquipment`，`src/modules/nonstandard-presales.js`；"手动登记方案设备"区的设备行按钮）。由 AI 结果采用、且尚无已确认或已应答条款、也未建方案的设备，可撤销：设备及其条款在一次修订内移除，记入修订记录，AI 结果页恢复"采用到人工复核"按钮，可重新采用。已有确认/应答的设备与手工登记设备不可撤销，避免误删复核成果。

已按旧版本采用、条款重复的工作稿：在"手动登记方案设备"区点该设备的"撤销AI采用"，再在 AI 结果中重新采用即可。

## 验证

`npm test`（`test_spec_adoption.mjs` 新增：重叠段重复、同句不同名称、跨段证据收窄后相同、同句不同值合并与不可偏离保留；撤销后移除与备份恢复、重新采用、已确认不可撤、手工设备不可撤）、`python dev_scripts/test.py --quick`、`npm run test:build` 通过；内联脚本语法检查通过。本地页面以合成工作稿实测撤销按钮：设备与条款移除、本机工作稿同步、无报错。
