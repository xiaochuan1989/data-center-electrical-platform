# v2.14.0 思考提取与语义复核

2026-10-19开始优化，2026-10-20完成验证与发布，按用户要求将规范书分析改为“保留思考、分批提取、单独复核”，替代v2.13.1固定关闭思考的临时处理。

## 实现

- DeepSeek官方deepseek-flash/deepseek-v4-pro启用thinking：设备识别/提取使用low，复核使用high。默认预算分别32768/65536 token，接口报告长度截断时可增加一次至65536/131072，然后继续分批；不关闭思考或接受截断JSON。具体参数依据[官方API](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)。其他兼容接口不强加DeepSeek字段，其思考能力由模型决定，仍执行单独的复核请求。
- 默认按3000字符分批识别/提取。所有提取完成后，使用全新请求复核当前原文、设备清单和参数：设备归属、值/单位、条件、可能漏项、设备遗漏、OCR歧义及冲突。每批最多16个完整参数，携带同片段其他批次摘要，避免将其他批次误报为漏项；输出截断可继续分批。
- 明确复核来自同一模型的单独调用，不宣称第二个独立模型或人工审核。模型疑点必须有真实连续原文、有效参数ID和位置；疑点仅供人工确认，不静默改写/删除/新增参数。
- 校验原文处理覆盖、逐参数复核标识及源/参数指纹。缺失/重复检查、不完整JSON、无依据疑点、失败/取消不提交新完成结果；参数或原文变化后旧复核失效。
- 页面、HTML和JSON保留复核意见，Excel新增“语义复核”工作表。旧v3提取工作稿仍可查看/导出，明确标记未执行语义复核；新v4稿必须有完整复核记录。
- 页面提示增加调用和耗时，区分预算重试、分批重试及终止，不把“模型未报告疑点”写成正确率保证。OCR符号/数值仍须看原图。

## 验证范围

合成测试覆盖错误设备归属、漏项疑点、逐参数/原文覆盖、预算参数、扩大预算/细分批次、非法疑点、缓存篡改失效、取消、旧稿兼容和各格式导出。既有模块/读取/OCR回归、Python质量套件及公开构建门禁继续执行；浏览器合成界面验收只使用专用本机测试接口，不发送客户资料到外部模型。

这保证处理链路和证据记录可核验，不证明模型一定找齐设备、参数或疑点。未读取用户密钥、未擅自重发客户资料，真实DeepSeek恢复效果及项目提取准确率需要实际资料对照验收。所有产物仍为待人工复核工作稿。

实际验证：npm全部模块测试通过，Python质量套件13/13，生产构建232文件及资源哈希门禁通过；本机浏览器完成2设备/4参数/1条合成疑点的完整界面流程。浏览器下载通道超时，未宣称实际下载验收通过；改用生产导出器生成文件，再以独立openpyxl读取核对Excel两工作表及JSON/HTML中的疑点和证据，一致且无公式。真实客户资料及密钥没有发送到测试接口。
