# 配电柜典型方案辅助生成：设计与验收

> 2026-10-01，用户同意先做配电柜案例校准与辅助生成，不先发布。沿用[总计划](nonstandard-presales-roadmap.md)和[契约v1](nonstandard-presales-contract.md)。本设计先于代码实施。

## 本轮目标与资料门槛

在现有非标方案编辑器增加“配电柜辅助生成”：已确认设备要求＋明确输入的回路表→未保存方案草稿→人工采用→同源清单/说明。不是自动元件选型、负荷设计或工程合格判定。

现有用户四份资料以UPS为主，仓库的电池、铜排数据和产品目录也不能替代配电柜询价案例。真实验收至少需要同一设备的技术要求与回路表/已有清单，以及业务人员的修改/采用反馈。资料缺失期间继续软件实现与显式合成测试；真实案例保持待验，不编造客户原文或参数，不扩大到扫描无关业务目录。已向用户询问案例路径。

## 输入与生成

- 两个可显式选择的结构骨架：进出线配置（不含母联）与含母联配置。它们只是组织回路的模板，不代表已核验的企业典型图或保护方案。模板不提供电压、电流、回路数量、品牌、型号、尺寸或数量1。
- 回路表支持Excel复制的制表符文本，固定四列：用途、名称、功能规格、每套数量；用途仅进线/母联/出线。也可使用竖线分列；禁止混用分隔符。示例提示只给列名，不预填客户参数。数量缺失保留未知，零、分数、非法数值拒绝，限制200组。名称必填，规格可未知；多规格分多行，不拆成假型号。
- 生成以本设备有效原文证据、人工确认且应答满足的标量为起点。采用配置中的明确输入保留；若与上述要求不同则阻断生成，提示先明确偏离，不能静默覆盖。未确认/失效/冲突/不适用条款不推值；全文条款只关联，不猜测型号或数量。
- 每类用途所有行数量已知时计算合计；与明确进线/母联/出线要求或采用值不一致时阻断。有未知行时合计未知，不把局部已知和当总数。骨架不含母联时不能输入母联行或正母联数量；含母联骨架不能明确填写母联数量0。缺进出线/母联的完整明细只能生成讨论稿。
- 每行数量是每设备数量，供货总量仍由既有核心乘设备套数。备用是否安装、是否计入出线由原文/人工明细明确，不根据“备用数量”自动加断路器。
- 型号、品牌、编码全部空，型号状态pending。生成依据注明回路表为人工设计输入，相关计数要求ID及保护要求可关联，但不冒充原文逐行提取。

## 状态与兼容

生成纯函数不改数据包。点击只载入一个新、未保存的草稿；有现存编辑或已保存方案时明确确认载入新草稿，取消保留原内容，已存方案不覆盖、不自动失效。生成草稿在保存前不能确认、导出或进入JSON备份。

尚未生成的辅助输入也保护：切换/重新载入/恢复前确认放弃，外部数量/要求提交不清空回路表；须先生成或明确放弃辅助输入，才能保存/确认/导出原方案。仅修改辅助输入不会冒充修改已存采用方案或撤销其确认。

保存沿用既有采用接口，origin可增加cabinet-assistant，并附可选assistant元数据：version=1、kind=cabinet-circuits、template、sourceRevision。记录用于说明生成来源，不代表规则或厂家核验。旧v1无该字段仍可读；恢复仍重新复核。助手来源的方案确认额外要求进/出线数量明确，选了含母联骨架则母联数量明确；骨架数量/明细及已有要求/型号/边界门槛同时检查。

方案说明从已存config/components动态生成，不缓存独立叙述。编辑后重新输出，不能沿用过期说明。说明明确骨架、来源版本、进出线分组、未知项与未完成专项校核；清单、Excel、HTML继续共用同一交付对象。模板告警不写成客户原文。

## 验收与发布边界

纯函数：设备隔离；只有有效确认值被带入；空/非法/过量回路表拒绝；未知不默认；已知多规格合计；数量/保护采用值错配阻断；无伪造型号；输入非突变；旧快照兼容；模板元数据拒绝篡改；恢复待复核；修改后的说明与清单一致；生成后仍是讨论稿。

浏览器：粘贴回路表→新草稿→保存→预览/HTML；取消替换不丢编辑；确认/导出拒绝未保存；其他品类无柜助手；已有UPS/母线数据不变；无pageerror/外部写请求；宽度1366/900可用。

运行现有全套测试及构建门禁。现有解析依赖本机打包另作明确实现与兼容验收，不能仅因某次CDN恢复称已解决。小范围试用和正式发布须另行授权；本轮不升级版本、不提交、不发布，不新增后端/上传/OCR。
