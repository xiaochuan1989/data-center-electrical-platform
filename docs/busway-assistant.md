# 智能母线询价助手：字段、关系与验收定稿

> 2026-10-01，先文档后实施。复用[数据契约](nonstandard-presales-contract.md)、[已有案例](micro-module-case-calibration.md)和现有编辑/输出入口；不等待单线图，不发布。

## 本轮闭环与输入边界

本设备有效原文条款（显式选择）＋人工分区域供货表＋数量归属依据 → 新的未保存询价草稿 → 人工修改/保存 → 同源方案说明、配置Excel、HTML及恢复JSON。选择、附表分类和保存不代表客户要求确认、满足应答或批准选型。

首版只接受“本区域整套系统”口径：用户明确选择region，Equipment.quantity明确为1，表示一个区域清单包，不是默认一套器件。附表箱数与米数直接进入区域组件数量，不再乘通道、机柜、A/B路数或PDU数。主/备区域各建一个母线设备项；不自动识别复杂表头或拆区域，不把区域间数量差异当冲突。

## 字段及方案—清单关系

| 原文称谓/人工表用途 | Component.role/单位 | 配置字段及核对 |
|---|---|---|
| 母线槽 | busway / m（米规范化为m） | buswayLengthM，完整明细合计；不拆成实际3m/2m/1m段数 |
| 主控箱 | controller / 套、台、个、只 | 新增controllerCount；不当进线箱或接口路数 |
| 端口箱 | endpoint / 套、台、个、只 | 新增endpointCount；保留原称谓，不自动等同始端箱 |
| 始端箱 | terminal / 套、台、个、只 | 既有terminalCount；箱体同一性须人工确认，不能重复登记同一物理箱 |
| 插接箱/插线箱 | plugbox / 套、台、个、只 | plugBoxCount；人工归属保留名称，不由箱数推回路/PDU数量 |
| 悬挂、连接、盖板、末端附件 | accessory / 人工单位 | 无明确数量为null，不套每米/每段系数 |

每组含未知数量时总数保持未知，不作部分合计。箱数为正安全整数；米数为有限正数且不超过安全数量范围；零行应明确移除，不补备用。人工表固定五列：用途、名称、功能规格、区域数量、单位；支持制表符或竖线，不混用；数量可留空/待确认/XX，范围/备选/表达式拒绝。数量归属依据必填，条款必须为本设备、未失效且全部证据有效。

新增controllerCount/endpointCount及controller/endpoint用途为v1可选扩展；旧方案、计算器桥接、快照和存储键不变。origin=busway-assistant，assistant={version:1,kind:busway-region,quantityBasis:region,sourceRevision,sourceRequirementIds,basisNote}，校验归属、来源关联、修订及规模；元数据是历史而非已确认原文参数。

## 参数、功能及未知

不从未确认自由文本自动提取电压/电流/频率/相制、N/PE比例、IP和短路值。多值/范围保留全文，不取最大，不把插接箱IP或品牌推广为全系统。有效人工确认且应答满足的标量可带入，与当前输入或表数量不一致阻断。

监控/通信、安装、支架附件等功能保留完整对应条款。不同箱体的监测范围、分时下电、分励脱扣、断路器品牌/系列及同品牌细项作为独立要求继续关联，不因有清单而自动满足，不把全文功能当已配置物理器件。

暂定/暂按/设计联络等限定语保留在假设及组件风险。选定证据同时有“三相四线制”与“三相五线制”则登记澄清/风险，不选一边；这是有限文本提示，不是完整冲突或标准校核。明确提及附件而未提供附件行时增加功能附件待确认项，数量/型号空。未识别原文仍留在要求及交付。

## 状态与输出

纯生成不突变；载入新未保存草稿，不覆盖已存方案。条款/表格/口径/依据编辑保护为未生成输入，切换/恢复须确认放弃，外部提交不清空；未生成不能保存/确认/导出旧方案；取消替换保留编辑。

区域助手保存后设备数量改为非1/未知：保留草稿、阻断确认，交付各行总数量null，不重复乘算；手工/计算器方案仍沿用原乘算。说明从当前保存的配置/组件动态生成，修改米数/箱数重保存再导出。共用要求、供货边界、规格/数量/单位、型号及风险门槛保留，不生成已核验接线图或完整生产BOM。

## 实施及验收顺序

1. 字段/用途/元数据扩展及五列表/区域草稿纯逻辑。覆盖单位、未知不局部合计、汇总、溢出/范围/非法、非1口径、跨设备/失效/伪证据、确认或采用值冲突、暂定/线制矛盾、空型号、不突变、恢复待复核及旧v1。
2. 接入现有编辑器；浏览器验证选择→生成→保存→修改→同源输出，未保存/未生成保护、外部提交、取消/旧方案保留、确认门槛、非1总量未知、品类隔离、1366/900及旧目录/母线/PDU兼容。
3. 复用本机真实原文及附表，人工归属两区域箱体和米数，生成私有讨论稿/恢复包；数量不重复乘，暂定/线制保留，源SHA-256不变。不冒充完整DOCX浏览器或业务验收。
4. 独立核对浏览器Excel/HTML/JSON的数量、未知、修订及动态说明；npm、公开构建、Python兼容检查和文档接续。

无后台/外部AI/OCR或上传，不升级、提交、推送、发布。文件读取本机依赖、自动表头归属、保护/路由设计、示意图及业务试用另行推进。
