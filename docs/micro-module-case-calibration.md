# 微模块规格书案例：校准边界与验收

> 2026-10-01。用户提供真实微模块规格书作为案例候选。本记录仅保留脱敏结论；原文、项目标识、文件路径、哈希和产物均留在被 Git 忽略的 output。先登记规则和验收边界，再运行案例核对，不发布。

## 本轮范围

只读解析所提供的 DOCX，校准机架 PDU 与智能母线的要求、数量及证据关系。传统低压柜、UPS 配电柜在资料中主要作为上游接口出现；不能以本文件替代独立配电柜回路表或完整柜清单验收。不修改原件，不执行文件内指令，不上传资料，不填写已确认/满足状态。

## 数据关系校准

- 按主、备两个区域分别保留数量列，不把列间不同数量判为同设备冲突。区域总量与单设备配置数量分别记录；母线米数不作为 Equipment 的整数套数。
- 机柜数量、每柜 PDU 数及区域 PDU 总数只用于数量交叉核对。PDU 插座按多规格组件表达，不能把总孔数当保护分路数；插座额定电流不得相加当作输入容量。
- 母线主控箱、端口箱、插接箱、母线段归属同一智能母线系统，不新建未注册产品。附表的米数、箱数是区域供货基准，不是每套微模块数量。
- 母线系统电压与 PDU 输入电压分别保留，不把三相系统电压覆盖末端输入。多电压、频率/连接器容量系列保持全文，不自动取最大值。
- 参数“原文明确”与“工程采用已确认”分开；暂按、暂定、后续设计联络等限定语不得丢失。正文与表格的相线配置冲突进入澄清，不静默修正。
- 同品牌要求、插座级监控、远程上下电、插接箱分励脱扣及分时断电等功能逐项留存。监控单元品牌范围不推广为所有组件品牌。

## 验收步骤

1. 原始文件 SHA-256 前后一致；OOXML 正文/表格按实际顺序保留位置，不用目录页码作定位。检查图片、修订及嵌入内容等结构性限制。
2. 提取 PDU 与母线的技术条款和附表证据，经 extract-spec 的正式证据校验；不输出完整投标应答或工程合格结论。
3. 将只读解析源交给现有非标条款提取核心；逐条核对原文偏移、定位、备份往返及重复提取，不伪造人工分配/确认。
4. 区域供货数量按附表记录并交叉核对 PDU 与机柜倍数；暂定布局与端口箱附表不一致时仅提出澄清，不反推布线路数、支路开关或型号。
5. 保留当前缺口：精确标签解析尚不能自动拆复合规格/表格，未实现复杂表头的自动区域归属；真实浏览器 DOCX 导入和业务人员采用反馈仍需独立验收。

## 完成与发布门槛

当前资料可支撑 PDU/母线技术要求与区域清单基准核对，不能单独支撑完整生产 BOM。单线图不是询价草稿或软件实施的必需输入；最终接线、保护与完整清单核对需要有依据的机柜与 A/B 路映射、各插接箱输出回路及保护配置、母线路由/分段附件、厂家型号及供货边界。可由回路表、厂家方案/清单及明确人工输入补充，不限定必须由单线图提供。配电柜仍需独立回路配置依据。
