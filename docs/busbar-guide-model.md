# 铜排指南模型（v2.12.3）

依据用户提供的《Copper for Busbars — Guidance for Design and Installation》，2014修订版，CDA/ECI。[原PDF](https://kupfer.de/wp-content/uploads/2019/11/Copper-for-Busbars.pdf)。本地下载在忽略目录 `output/reference-documents/`，不随网站发布PDF。

## 自然对流：第16–17页，2.2.1.1及图5

指南的单位面积热流密度：竖直面 q=7.66×ΔT^1.25/L^0.25；水平面 q=5.92×ΔT^1.25/L^0.25。q单位W/m²，L必须以mm代入。L为竖直表面高度或水平表面宽度，不能直接代入m。

本工具按每米铜排计算长边四个面，忽略两端面的散热：

| 安装 | 宽面组（两个面） | 窄面组（两个面） |
| --- | --- | --- |
| 水平走向、宽面竖直 | 竖直公式，L=宽度，面积=2×宽度/1000 | 水平公式，L=厚度，面积=2×厚度/1000 |
| 水平走向、宽面水平 | 水平公式，L=宽度，面积=2×宽度/1000 | 竖直公式，L=厚度，面积=2×厚度/1000 |
| 沿长度方向竖直 | 竖直公式，L=输入的连续散热高度 | 竖直公式，L=输入的连续散热高度 |

各组q×有效面积相加。页面h只是面积加权的等效对流系数，不用于掩盖各面区别。沿长度竖直的初始高度1000mm是待核实的输入，不是指南的统一高度。现有有效面积系数按同一比例作用于各面，不能替代实际遮挡和流动计算。

## 辐射：第18–19页，2.2.1.3

新增周围表面发射率ε₂及等效辐射环境温度；空气温度用于对流，周围表面温度用于辐射。留空时假设周围表面与柜内空气同温，并显示该假设。

相对发射率 e=ε₁ε₂/(ε₁+ε₂−ε₁ε₂)。辐射功率采用e×F×σ×As×[(T铜排+273.15)^4−(T周围+273.15)^4]。保留σ=5.670374419×10⁻⁸的精度，不采用指南四舍五入的5.70×10⁻⁸。ε₂=1是黑体周围表面假设；视角系数F为单独的等效可见程度。这是简化两表面模型，不是整柜辐射网络或有限面积精确视角计算。并排同温铜排相对面不能按完全对外辐射计算。

周围表面高于铜排温度时，辐射项为负，计入热输入；最高温度下总净散热不大于零时阻止输出载流量。工作温度通过对流、辐射与温度相关电阻共同迭代；若解在空气温度以下，用相同经验系数和温差绝对值表示反向对流热输入，此为工具的对称近似扩展，不是指南对冷壁面工况的独立验证。

| 表面预设 | 铜排ε₁ | 来源 |
| --- | ---: | --- |
| 明亮金属 | 0.10 | 指南典型值，默认；不特指镀锡 |
| 部分氧化铜 | 0.30 | 指南典型值 |
| 重度氧化铜 | 0.70 | 指南典型值 |
| 非金属哑光漆 | 0.90 | 指南典型值；未计涂层热阻 |
| 镀锡0.05/0.03 | 0.05/0.03 | 保留旧假设，需项目依据，不标作指南值 |
| 文章部分氧化铜 | 0.40 | 保留原文章假设 |

默认改为指南自然对流与指南明亮金属预设；表面和模型选择移到主表单。80%设计系数、15K柜内空气温升和F=0.8仍为本工具的工程假设，不能视为指南推荐或实测值。旧经验式、Nu/Ra模型、原表反校和自定义h可显式选择；文章1762A算术复现保持独立。

## 可重复工况

“载入100×10指南校核工况”：35℃空气/周围表面、65℃最高温度、宽面竖直、ε₁=0.30、ε₂=1、F=1、面积系数1、直流、ρ₂₀=1.7241×10⁻⁸Ω·m、α=0.00393、100%设计系数。

- 宽面自然对流34.014206W/m，窄面4.674695W/m，总对流38.688901W/m。
- 辐射15.187425W/m，热平衡电流1629.510644A；改成80%设计系数，建议电流1303.608515A。
- 仅改为指南明亮金属ε₁=0.10，热平衡电流1468.432791A。

这些是明确假设下的指南计算，不以接近文章1762A或某工作簿值作为准确性验证。仅温度归一值保留周围表面相对空气的温差；归一条件净散热≤0时显示无法归一，避免输出NaN或0A。

指南自然对流公式的依据是自由空气。工具仍是单片初算；并联互热、风冷、绝缘/漆膜热阻、连接损耗和整柜通风不在本次模型内。交流仍需经核实的Rac/Rdc系数，未把第22页之后的集肤/邻近曲线自动外推到实际柜内排列。
