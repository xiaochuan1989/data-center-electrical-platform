# PDU规范条款辅助生成：设计与验收

> 2026-10-01，先文档后实施。复用[数据契约](nonstandard-presales-contract.md)、[微模块案例](micro-module-case-calibration.md)及现有方案编辑器。缺单线图不阻断询价草稿，暂不发布。

## 本轮闭环

已登记PDU → 人工分配全文要求 → 显式选择用于生成的条款 → 候选配置与多规格功能清单 → 新的未保存草稿 → 人工修改/保存 → 同源说明、Excel、HTML及JSON。选条款不等于确认客户要求或满足应答。

首版只支持用户明确选择机架PDU；不自动按名称推类型，不套用柜式PDU模板。沿用设备项隔离主/备区域：设备数量是本区域PDU总量，组件数量是每条PDU数量；不自动把每柜两条再乘一次，不读取母线箱数生成PDU。

## 字段与关系

| 原文/输入 | 候选及清单关系 | 未确认边界 |
|---|---|---|
| 明确“输入AC…V …A”复合规格 | voltageV/ratedCurrentA；输入功能项 | 接口数量未知，不默认1；不由电压猜相制 |
| 明确“输出…位…A插座＋…位…A插座” | 按每种原文接口规格分output行；完整分组的位数合计outputCount | 总孔数不是保护分路数；额定值不相加推输入容量 |
| 每柜PDU数量、A/B条款 | 保留冗余功能全文，不更改Equipment数量 | 每柜数量不是每条PDU输入数量 |
| 本地计量、插座级监控、远程上下电、同品牌、安装 | 保留完整对应功能原文，关联要求；必要功能项数量未知 | 不自动配物理模块数量、品牌、接口协议或开关型号 |
| 原文多值、范围、备选、不明确输出语法 | 保留要求及澄清；不得部分识别后称完整清单 | 不取最大、不套默认值、不静默丢未识别片段 |
| 已确认且应答满足的有效标量、当前明确采用输入 | 复用既有值；与候选不同则阻断并提示复核 | 不覆盖偏离决定；未确认来源始终是候选 |

生成仅从选定、本设备、未失效且全部证据有效的要求读取。对每个需求池的多个候选逐个核对；明确同字段不同值或多套不同插座组合不能自动合并，须拆设备/选择澄清。限制选取数量和文本规模，合法数量为安全整数，计数/总量溢出拒绝。所有原始要求继续关联方案，未识别也不能自动满足。

参数“暂定、后续设计联络”等限定语保留在清单风险和假设中。缺规格、数量、保护或厂家型号保持空/null；不新增自动确认、厂家应答、生产图或标准合格判断。

## 状态及兼容

纯生成函数不改包；生成载入新未保存草稿，取消不丢编辑、不覆盖已存方案。助手条款选择作为未生成输入保护：切换/恢复/重新载入需确认放弃，外部提交不清空，保存/确认/导出旧方案前须生成或明确放弃。生成后选项保留可再次调整。

新增origin=pdu-assistant及可选assistant={version:1,kind:pdu-spec,sourceRevision,sourceRequirementIds}。仅PDU允许，来源要求必须属于同设备，版本/修订和ID验证；旧v1无该元数据兼容。恢复仍待复核。助手方案确认至少需明确机架类型、输入电压/电流、输出总数及明细，沿用所有要求、数量、边界、型号和风险门槛。

方案说明由当前存储的config/components动态生成，不缓存第二套清单；人工编辑插座数量/输入参数后重新保存、导出，说明跟随当前值，不复述原候选为已采用配置。

## 验收用例

- 合成纯函数：复合输入、多规格输出、输出合计、无默认输入数/保护分路/相制；限制与范围不推值；未知分组不作部分合计；不把备用/总负载/输入容量误当插座；数字/品牌/型号不补造。
- 证据/状态：跨设备/未分配/失效/伪证据拒绝；同字段矛盾和多候选输出不静默选值；确认值或采用输入错配阻断；输入对象不突变；来源元数据篡改拒绝；旧柜/母线与快照兼容。
- UI：显式选择条款和机架类型→新未保存草稿→保存→修改→说明/清单/导出一致；未生成选择保护、外部提交保留、取消替换保留旧方案，其他品类无PDU助手；未核对型号/风险/要求不能确认；900/1366宽度及pageerror/外部写请求检查。
- 真实案例：复用私有只读源，仅在忽略目录人工归属形成待复核工作稿；验证候选原文、区域PDU总量与每条插座总量的关系，不替用户确认，不把合成浏览器测试算作业务通过。

运行全套npm回归和公开构建门禁。文件CDN依赖本机化、自动多区域表头归属、完整保护设计另作后续工作；不新增后台/外部AI/OCR，不提交、推送、升级或发布。
