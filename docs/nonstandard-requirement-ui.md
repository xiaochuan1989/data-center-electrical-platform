# N2 需求提取与复核入口设计

> 2026-10-01，先定稿后实现。沿用[数据契约v1](nonstandard-presales-contract.md)。本轮目标是需求工作稿，不是正式技术应答或完整方案包。

## 入口与步骤

工具中心增加独立“非标技术要求复核（基础版）”，不增加项目工作台，也不影响UPS产品库导入。独立模块依次提供：

1. 手工登记配电柜、PDU或智能母线设备项，数量可未知；不会根据文件标题自动创建最终设备。
2. 粘贴文本或在本机读取TXT/MD、DOCX、文字PDF、XLSX。来源列表可查看原文、替换重传。XLSX是需求专用入口，不读写产品目录；不执行宏、公式、外链或文档内指令。
3. 按资料生成待复核条款；默认全部“待分配”。明确选定设备后再解析该条款的品类字段，保留不能识别的全文条款。不得自动把整份文件所有参数应用到一个设备。
4. 每条可选设备、字段、确认值、禁止偏离三态与人工应答，填写原因后确认。按图/占位仍显示未知；原文或证据失效则阻断。修改界面中的复核输入立即撤销该条已确认状态。
5. 展示未分配、未知、冲突、失效及未复核清单；提供独立JSON工作稿下载/恢复与技术要求Excel工作稿，输出明确标记待复核，不叫“全部合规”。

本轮不提供自动设备识别、元件选型/整柜方案、生产图或价格，不为N3/N4提前验收。

## 提取与位置

规则只识别明确标签与单值（例如“额定电流：数字A”）；≥/≤、范围、跨设备列表、多种容量、无法映射的单位、型号/功能要求均保留全文条款，等待人工拆分/确认。不从UPS过载时间推后备时间，不把最大并机能力作安装数量。

- TXT/MD按文本行定位，UTF-8文本优先，乱码需明确报错而非伪造成功。
- DOCX使用mammoth转为段落/表格HTML，在本机DOM解析；普通段落编号和表格行号基于解析结果，标为“解析段落/表格”，不冒充Word页码。
- PDF按真实页序分段，空白/无字页明确告警，不调用外部OCR。后续按[本机化定稿及实际验收](local-file-reading.md)固定PDF.js6.3.289及同源worker/中文映射/字体资源，DOCX与XLSX读取同样取消CDN；不上传客户内容，扫描件仍需另行处理。
- XLSX使用现有SheetJS只读解析，以工作表/单元格定位，保留单元格可见文本与禁止偏离列的同一行标记。公式只保留原式并告警，不求值，不将缓存当作已验证参数；隐藏表和合并格提示另行核对。

补充实际样例核对：有明确“内容＋要求＋禁止偏离项”表头时，仅将要求列的数据单元格提为条款，并关联同一行内容标题/禁止偏离标记；分数、表头与厂家应答只保留在来源中，不混入客户要求。无法唯一识别要求列时保留单元格工作稿并告警，不能猜列。Source.segment可选`role/contextTitle/contextCell`保存这一显式表头映射，标题必须能在同表同单元格原文核对。
- 文件读取有大小/页面/单元格/文本量上限，失败不改变当前包。异步读取期间包或当前原文改变时放弃旧结果；不覆盖后来的输入。

相同设备同字段候选进入统一冲突池；重复点击不重复追加同一片段。来源替换使旧要求stale，重新提取后可重新映射。未分配条款通过显式重映射归属设备并保留候选证据，不丢失原文。

## 留存与安全

新增独立localStorage键`nonstandard_presales_working_v1`，不接入旧项目/UPS键。初始不保存任何客户资料；用户勾选“仅本机自动保存”后才写入，每次落盘异常显示失败，不能报告保存成功。可下载工作稿JSON备份；恢复必须验证版本/证据并回到待复核。恢复会替换当前独立工作稿，须用户明确确认。

关闭自动保存只停止后续写入并保存偏好，不删除既有缓存。重开页面仍可恢复旧缓存，复核状态重新确认；关闭期间的新改动须主动下载备份。

原文/文件名/用户内容全做HTML转义。Excel把可能触发表格公式的文字作为字符串保存。没有本轮外部AI/OCR调用、云端存储、Git提交、版本升级或发布。

## 验收门槛

纯函数：原文定位、标量冲突、跨设备隔离、重映射、禁止偏离/占位、重复提取、来源替换、JSON版本与伪证据拒绝。

真实浏览器：工具入口、三品类设备、文本提取/分配/确认/修改失效、文件需求导入不改UPS库、空白或不支持文件不破坏包、异步旧结果拒绝、本机保存失败提示、备份恢复、Excel工作稿、1366/1920/900宽度与pageerror。合成软件测试与真实业务验收分开记录，真实UPS资料仅复核相关条款定位，不宣称本入口完成UPS选型或完整业务验收。

## 本轮结果与限制

2026-10-01基础版已接入并通过上述合成软件/浏览器检查；五组Node回归、构建门禁及Python13/13通过。四份真实原始资料只读解析检查通过，需求XLSX按明确要求列保留37条工作稿及禁止偏离标记；未自动确认或作厂家应答。详细接续见[实施计划](nonstandard-presales-roadmap.md)。

后续N3已在同入口增加[手工采用方案与配置清单](nonstandard-scheme-ui.md)，入口改名“非标配电售前方案”，统一JSON备份；需求Excel导出为本机静态XLSX。解析依赖本机化、完整N2及5份真实资料三环境导入通过，见[读取验收](local-file-reading.md)。后续[条款分页/按资料复核](requirement-pagination.md)已接入：默认20、可选10/20/50，资料/关键词/设备/状态交集，有界待处理/修订摘要；切页保留会话行草稿，来源变化清除不兼容草稿，恢复可取消，输出仅含已记录包。1196条真实工作稿开发/生产子目录遍历、导出及三个宽度通过；草稿刷新不持久化，不视为工程采用。

尚未完成：各品类真实业务验收、范围/上下限自动判定、自动设备识别、完整品类规则与正式方案包。N2基础版不能替代旧UPS S4验收。
