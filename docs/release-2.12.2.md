# v2.12.2 铜排对比口径修正

2026-10-11（北京时间），修复用户指出的v2.12.1对比问题，沿用本次铜排修正及发布授权。

## 修正

- “复现文章原例（1762A）”独立采用原文Kt=9.8475、ρ=2.09×10⁻⁸Ω·m、100×10mm、35℃环境/65℃铜排、30K温升。完整分子得到1763.44A，使用原文中间近似0.0649得到1762.18A；清楚展示精度区别。
- 工程工况按钮更名为“载入100×10工程校核工况”，不再将更换Kt、ρ后的1673A称作同参数原文复现。
- 增加原文与当前工程计算的逐项参数表，列出温度、Kt、电阻率、特征长度、散热处理和设计折减；不将不同模型差值称为准确性误差。
- 本地工作簿与仅温度归一值中删除“同条件差异”、百分比及其准确性颜色。两份来源定义/版本未核实，不以本地1490A/1810A列名断言文章查表错误。
- 顶部温升说明随外部环境、工程温升、柜内空气温升更新；最高65℃与温升65K不再混淆。

原文复现按钮不覆盖工程输入或工程计算结果。工程热平衡算法和原始查表数据保持不变。
