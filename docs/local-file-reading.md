# 文件读取本机化：实施与真实导入验收定稿

> 2026-10-01。先定稿后实施；仅替换解析依赖与读取安全/可用性，不扩大业务语义、不发布。接续[总计划](nonstandard-presales-roadmap.md)。

## 目标与非目标

DOCX、文字PDF、XLSX、UTF-8文本在浏览器本机读取。页面与全部解析资源由同一静态站点/本机HTTP服务提供；浏览器不请求解析CDN，不上传原文、不执行文档指令/宏/公式。离线指“页面和依赖已由本机静态服务提供、阻断互联网仍可解析”，不是承诺首次断网访问远程站点、file://双击或离线缓存/PWA。

新非标入口与旧UPS Word/PDF、目录Excel导入均改同源依赖；新非标静态Excel写出器不变。保留既有存储键、包v1、人工归属/确认和异常不覆盖状态；读取成功不代表提取语义、规范满足或业务采用通过。

## 固定依赖与兼容边界

- Mammoth固定1.13.0，浏览器独立构建由npm锁定包提供。DOCX转HTML的选项放在第二参数，显式externalFileAccess=false并禁用图片转换；只取脱离页面的文本，不插入生成HTML，保留messages告警与解析位置（不是Word页码）。旧UPS仍取原始文本。
- PDF.js最终固定6.3.289；首次安装核验发现原拟5.6.205仍在[新披露影响范围](https://github.com/advisories/GHSA-hq66-cqwq-w95j)，调整后再实施，不采用高危中间版。同版本legacy ESM主库/worker及cmaps、standard_fonts、wasm一并发出；保留许可，不带示例、源映射或客户文档。首次模块异步加载提供就绪Promise，文件入口等待并友好失败。getDocument统一同源资源地址，isEvalSupported=false；不执行PDF脚本、不自动OCR。原3.11.174也属于[历史漏洞影响范围](https://github.com/mozilla/pdf.js/security/advisories/GHSA-wgrm-67xf-hhpq)，不直接原样本地化。
- SheetJS CE固定0.20.3从[官方发行源](https://docs.sheetjs.com/docs/getting-started/installation/standalone/)锁定tarball，用于所有Excel读取；保留xlsx-js-style 1.2.0仅作为既有样式写出兼容引擎。旧XLSX全局仍提供样式写出，read/读取函数转发CE，新非标读取显式使用CE；不把旧样式包等同新解析器，不宣称完整第三方安全审计。验收旧样式导出保留及旧读取身份。
- npm锁文件记录精确版本/完整性，安装不运行生命周期脚本；首次省略可选包会移除Vite所需平台构建依赖，最终按npm正常平台可选依赖恢复，仅本工作区开发依赖，无服务器服务安装。原生依赖不进入浏览器解析资源清单。

## 资源发布与失败方式

新增构建/开发插件按允许清单从锁定node_modules发出vendor资源，dev与build相同路径；不遍历/复制业务目录，不依赖被忽略的public手工资源。生成资源是构建产物，不手写第三方代码。保留第三方许可；主库/worker版本、文件哈希和资源数量可重算核对。部署base为相对路径，兼容GitHub Pages子路径；静态构建及预览都需验证，而不只dev可用。

index取消CDN主/备用加载，保留ensureLib明确本机资源缺失提示；解析失败不退回外网。PDF主库、worker、字库/映射同源；没有后端、自动升级/CDN备用或额外AI。构建门禁拒绝远程解析地址及缺资源，继续检查原始工作簿/PDF/价格/客户标识未进入公开构建。

现有20MB、800000字符、12000单元格、PDF150页门槛保留；空/扫描页、加密/损坏、旧DOC/宏工作簿、UTF-8错误及库缺失均明确提示，保持原资料/要求。PDF页序、DOCX解析段落/表格、XLSX表/单元格原文可核对；不因升级强求位置编号与另一OOXML解析器相同，不重绑定历史证据。

真实负例发现SheetJS会把仅改XLSX后缀的任意字节当成文本表格读取；新需求入口增加ZIP文件头检查，拒绝损坏/改后缀/加密容器，不退回CSV读取。旧目录入口保留原XLS兼容，未扩大其格式契约。

## 实施及验收顺序

1. 锁定依赖与允许清单插件，替换index加载/共用PDF参数，修复DOCX选项与新入口文案。PDF 6使用PDFDocumentLoadingTask.destroy释放资源（不再调用PDFDocumentProxy.destroy），成功及失败均释放。纯回归覆盖参数同源、无eval/外部文件、异步就绪、缺库/空/类型/限量及显式测试解析注入兼容；浏览器CE缺失不退回旧样式写出器读取。
2. 全套npm/Python、构建门禁；校验许可证/依赖版本、dist全部vendor哈希、子路径HTTP响应和主库/worker一致；独立检查样式Excel输出仍可读。
3. Playwright新隔离会话在“阻断外部网络但允许本机静态服务”条件下测试真实文件选择控件：既有微模块DOCX及原四份UPS文件（2 DOCX、24页PDF、关键参数XLSX）。原文件前后SHA-256对既有基线5/5一致；不写原目录、不外发、不确认采用，私人路径/全文/结果只放忽略output。
4. 新入口验证每份读取/来源位置、提取后证据、未知/禁止偏离、重复提取、备份恢复；旧UPS验证真实DOCX/PDF及目录导入兼容（需求XLSX不误用作目录）。使用适当合成样例补公式/隐藏/外链图片、不执行文档指令、空/扫描/损坏/缺worker及读取过期不覆盖；实际资料成功不能代替负例。
5. 生产build预览及GitHub Pages类似子路径重复真实读取，记录无外部解析请求/客户上传、无pageerror和新结果时间戳。软件/文件导入通过与未完成业务语义/工程采用明确区分，回写文档，不升级/提交/推送/发布。
